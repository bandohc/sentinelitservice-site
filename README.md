# Sentinel IT Service launch site

This is a static site for Sentinel IT Service. It is designed to run on GitHub Pages or Cloudflare Pages at `sentinelitservice.com`.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `CNAME` — custom domain for GitHub Pages

## Free launch path

1. Create a public GitHub repository and upload these three files.
2. In the repository, open **Settings → Pages** and publish from the main branch.
3. Add `sentinelitservice.com` as the custom domain.
4. In GoDaddy DNS, point the domain records to the GitHub Pages values GitHub provides.
5. Create the custom mailbox with Zoho Mail, then add Zoho's verification and MX records in GoDaddy DNS.

The page intentionally uses email links instead of a paid form service. Once the Zoho mailbox is active, the consultation buttons will deliver to `clint@sentinelitservice.com`.
